CONVRGENCE 繁體中文化（非官方）
版本 1.3（2026-10-17）｜對應遊戲 2026-10-01 更新後的版本
====================================================================

把遊戲裡的英文文字換成繁體中文：劇情對白、任務目標、教學提示、
文件、物品名稱與說明，共約 1,700 條。
譯文是預先翻好的固定內容，不連網、不是即時機器翻譯。
遊戲本身的檔案完全不會被修改。


■ 安裝
--------------------------------------------------------------------
【方法一：安裝程式】
執行 CONVRGENCE-zh-TW-v1.3-Setup.exe，它會自動從 Steam 找到遊戲，
按「安裝中文化」即可。
Windows 若跳出「Windows 已保護您的電腦」，按「其他資訊」→「仍要執行」。
（這個程式沒有付費的數位簽章，所以 Windows 不認得它。）

【方法二：手動解壓縮】
1. Steam 收藏庫 → 對 CONVRGENCE 按右鍵 → 管理 → 瀏覽本機檔案。
   會打開遊戲資料夾（裡面有 CONVRGENCE.exe）。
2. 把這個壓縮檔「裡面的所有東西」解壓縮到那個資料夾。
   解完之後，winhttp.dll 要跟 CONVRGENCE.exe 放在同一層。
3. 遊戲內的語言請維持 English（不要選俄文）。
4. 照常從 Steam 啟動。

第一次啟動會多花 10～30 秒準備，會跳出一個黑色的主控台視窗，屬正常現象。
之後啟動就會快很多。


■ 開關中文
--------------------------------------------------------------------
遊戲完全關閉後，雙擊遊戲資料夾裡的 toggle-chinese.bat。
執行一次切換成英文，再執行一次切回中文。翻譯檔不會被刪除。


■ 解除安裝
--------------------------------------------------------------------
用安裝程式的「解除安裝」按鈕。
或手動：刪掉遊戲資料夾裡的 winhttp.dll，遊戲就會回到原版。
要清乾淨的話，再刪除這些：
  BepInEx\  dotnet\  doorstop_config.ini  .doorstop_version
  toggle-chinese.bat  Toggle-Chinese.ps1  README-zh-TW.txt  LICENSES\
也可以在 Steam 用「驗證遊戲檔案完整性」，但它不會刪掉多出來的檔案。


■ 遊戲更新之後
--------------------------------------------------------------------
・大部分翻譯會繼續有效。開發者改寫過的句子會顯示回英文，
  等這個漢化包推出新版即可。
・模組框架會在遊戲更新後自動重建所需的檔案，
  所以更新後第一次啟動又會比較慢，這是正常的。


■ 已知限制
--------------------------------------------------------------------
・少數文字要等畫面重新顯示一次才會變成中文。
・人名多數保留英文拼法（例如 Evglevsky）。
・遊戲內建的中文字型沒有 。、「」—… 這幾個符號，遊戲裡會改用
  ｡､｢｣－... 顯示（外形一樣，只是比較窄）。
・機密文件上的塗黑，中文版改成跟著中文字走，遮住的內容與英文版相同。


■ 漢化包裡的 ConvrgenceZhFix 外掛
--------------------------------------------------------------------
光靠翻譯檔解決不了的顯示問題，由 BepInEx\plugins\ConvrgenceZhFix.dll 處理：
・機密文件：關掉照英文排版擺的黑條（否則會壓在中文字上），
  並拿掉打字機字型的粗外框（否則中文筆畫會黏成一團）。
・把遊戲內建的日文、韓文字型接在中文字型後面，補上缺的全形標點。
・紙本文件與字條的中文自動放大、拉開字距與行距，在頭盔裡比較好讀
  （放得下才放大；設定檔的 [Paper] 可以調整，MaxScale 設 1 就是原本大小）。
設定檔在 BepInEx\config\zh-tw.convrgence.textfix.cfg，一般不需要改。


■ 譯名對照
--------------------------------------------------------------------
the Zone = 禁區      artifact = 遺物      raid = 出擊
Hideout = 藏身處     stalker = 潛行者     convergent shift = 匯聚偏移

任務地點一律用出擊選單上的四張地圖名稱：森林、車庫合作社、地下設施、死城。
任務裡的「(CITY)」「the City」都是死城（遊戲沒有叫「城市」的地圖）。
